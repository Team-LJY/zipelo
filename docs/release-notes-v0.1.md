# Zipelo v0.1 릴리스 노트 (초안)

이 문서는 초안이며 릴리스는 게시되지 않았습니다. 게시는 이준영 님 승인 후에 합니다.

## 지원 형식

- ZIP 목록 보기, 해제, 생성
- 암호 ZIP: ZipCrypto 해제, AES-256 해제와 생성
- 7z 해제(LZMA, LZMA2)
- TAR, GZ, TAR.GZ 해제

## 지원하지 않는 기능

- RAR
- 손상된 압축파일 복구
- 미리보기
- 분할 압축, 7z 생성, TAR.BZ2, TAR.XZ
- JAR 같은 앱과 문서용 컨테이너

## 안전 동작

- 압축파일 안의 경로가 지정한 폴더 밖을 가리키면 쓰지 않고 거부합니다.
- 기존 파일을 덮어쓰지 않습니다.
- 해제 총량이 16 GiB를 넘으면 거부합니다.
- 디스크 여유 공간이 부족하면 오류로 알립니다. 임시 출력은 정리를 시도하지만, 이미 만들어진 결과와 정리에 실패한 임시 파일은 남을 수 있습니다.
- 압축 처리는 별도 작업자 프로세스에서 하며 앱이 종료되면 작업자도 정리됩니다.

## 설치

- Windows: 설치 파일을 더블클릭하면 현재 사용자 폴더에 앱과 작업자를 설치합니다. 마지막 화면의 [적용]을 누르면 .zip, .7z, .tar, .gz, .tgz 연결 후보를 등록하고 Windows 기본 앱 설정 화면을 엽니다. 기본 앱은 설정 화면에서 직접 선택합니다. [마침]만 누르면 연결 후보를 등록하지 않습니다.
- Ubuntu: .deb를 sudo로 처음 설치하면 zip, 7z, tar.gz 연결을 xdg-mime으로 바로 적용합니다. 업그레이드에서는 사용자의 기본 앱 선택을 유지하고, 제거해도 사용자 MIME 설정은 지우지 않습니다.

## 알려진 한계와 남은 위험

- 해제 총량이 16 GiB 이하이면 압축률이 매우 높은 파일(압축 폭탄)도 디스크에 그대로 풀릴 수 있습니다. 해제 전 여유 공간 확인과 사용자 취소로 줄이지만 완전히 막지는 못합니다.
- 7z 해제와 ZIP 생성은 스트리밍과 새 한도 적용이 진행 중입니다. 완료 전에는 기존 입력과 해제 크기 제한이 남아 있을 수 있습니다.
- Windows에서 실제로 실행해 확인하지 않았습니다. 현재는 Linux 시험과 Windows 교차 빌드만 확인했습니다.
- Windows 설치 파일과 Ubuntu .deb를 로컬에서 만들 수 있습니다. Ubuntu .deb는 Ubuntu 26.04에서 설치, 실행, 제거를 확인했습니다. 다른 Ubuntu 버전과 Windows 설치 실기는 확인하지 않았고, 설치 파일은 아직 릴리스에 게시하지 않았습니다.
- Windows는 앱이 기본 프로그램을 강제로 바꾸지 못합니다. 설치 마지막의 [적용]은 Zipelo를 연결 프로그램으로 등록하고 Windows 기본 앱 설정 화면을 엽니다.
