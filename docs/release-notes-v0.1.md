# Zipelo v0.1 릴리스 노트

[v0.1.0은 2026-11-13에 게시됐습니다](https://github.com/Team-LJY/zipelo/releases/tag/v0.1.0). 아래 지원 범위와 커밋별 시험 기록은 v0.1 당시 스냅샷이며 현재 main의 검증 결과가 아닙니다. 이후 개선은 [v0.2 릴리스 노트 초안](release-notes-v0.2.md)을 참고하세요.

## 지원 형식

- ZIP 목록 보기, 해제, 생성
- 암호 ZIP: ZipCrypto 해제, AES-256 해제와 생성
- 7z 해제(LZMA, LZMA2)
- TAR, GZ, TAR.GZ 해제

## 지원하지 않는 기능

- RAR
- 손상된 압축파일 복구
- 미리보기
- 분할 압축, 7z 생성, TAR.BZ2, TAR.XZ
- JAR 같은 앱과 문서용 컨테이너

## 안전 동작

- 압축파일 안의 경로가 지정한 폴더 밖을 가리키면 쓰지 않고 거부합니다.
- 기존 파일을 덮어쓰지 않습니다.
- 해제 총량이 16 GiB를 넘으면 거부합니다.
- 디스크 여유 공간이 부족하면 오류로 알립니다. 임시 출력은 정리를 시도하지만, 이미 만들어진 결과와 정리에 실패한 임시 파일은 남을 수 있습니다.
- 압축 처리는 별도 작업자 프로세스에서 하며 앱이 종료되면 작업자도 정리됩니다.

## 설치

- Windows: 설치 파일을 더블클릭하면 현재 사용자 폴더에 앱과 작업자를 설치합니다. 마지막 화면의 [적용]을 누르면 .zip, .7z, .tar, .gz, .tgz 연결 후보를 등록하고 Windows 기본 앱 설정 화면을 엽니다. 기본 앱은 설정 화면에서 직접 선택합니다. [마침]만 누르면 연결 후보를 등록하지 않습니다.
- Ubuntu: .deb를 sudo로 처음 설치하면 zip, 7z, tar.gz 연결을 xdg-mime으로 바로 적용합니다. 업그레이드에서는 사용자의 기본 앱 선택을 유지하고, 제거해도 사용자 MIME 설정은 지우지 않습니다.

## 알려진 한계와 남은 위험

- 해제 총량이 16 GiB 이하이면 압축률이 매우 높은 파일(압축 폭탄)도 디스크에 그대로 풀릴 수 있습니다. 해제 전 여유 공간 확인과 사용자 취소로 줄이지만 완전히 막지는 못합니다.
- 7z 해제는 스트리밍으로 처리하며 해제 총량 16 GiB 한도와 해제 전 여유 공간 확인을 적용합니다. ZIP 생성도 원본 총량 16 GiB 한도를 적용합니다. ZIP 구조와 암호화로 늘어나는 크기는 이 한도에 포함하지 않습니다.
- Windows 설치 파일은 기존 설치 위에 덮어쓰는 업데이트를 지원하지 않습니다. 제거 후 다시 설치하세요. Ubuntu .deb는 업그레이드를 지원합니다.
- AES-256 암호 ZIP은 Windows 탐색기 기본 기능으로는 열 수 없고, Zipelo나 7-Zip으로 열어야 합니다.
- `eca9a73` 설치 파일은 Windows 11 VirtualBox VM에서 설치와 제거, 일반 ZIP 및 AES-256 암호 ZIP의 폴더 포함 생성과 해제를 확인했습니다. 각 형식에서 파일 4개의 해시 일치, 한글 경로와 빈 폴더 보존을 확인했습니다. 저장 미확인 상태에서도 완료 안내와 [폴더 열기]가 유지되고, 저장 경고는 자세히 보기에만 표시되며, 탐색기가 열리는 것을 확인했습니다. 로컬 검증 기록은 `tests/windows-eca9a73/results.json`입니다.
- 사용자 PC에서는 이전 설치본으로 OpenGL 요구 버전을 지원하지 않는 Windows 11 환경의 압축 해제를 확인했습니다. 압축 만들기와 새 UI가 포함된 `eca9a73` 설치본의 사용자 PC 확인은 대기 중입니다.
- 이번 Windows VM 검증에는 기본 앱 등록, 잘못된 암호 재시도, 디스크 동기화 실패 주입 시험을 포함하지 않았습니다.
- Windows 설치 파일과 Ubuntu .deb를 로컬에서 만들 수 있습니다. Ubuntu .deb는 Ubuntu 26.04에서 설치, 실행, 제거를 확인했습니다. 다른 Ubuntu 버전은 확인하지 않았고, v0.1.0 설치 파일은 위 릴리스에 게시됐습니다.
- Windows는 앱이 기본 프로그램을 강제로 바꾸지 못합니다. 설치 마지막의 [적용]은 Zipelo를 연결 프로그램으로 등록하고 Windows 기본 앱 설정 화면을 엽니다.
