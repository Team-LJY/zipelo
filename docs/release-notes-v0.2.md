# Zipelo v0.2 릴리스 노트 (초안)

이 문서는 main `3a77cfd`에 반영된 구현 범위의 초안입니다. v0.2 릴리스와 설치 파일은 아직 게시하지 않았으며, README 다운로드는 v0.1.0입니다. 출시 후보 실기와 실패 시 출력 정리 검증은 진행 중입니다. 릴리스 게시는 별도 승인을 따릅니다.

## 추가된 기능

- **미리보기:** 파일 하나를 고르고 [미리보기]를 눌러 UTF-8 텍스트(`.txt`, `.md`, `.log`, `.csv`, `.json`)와 정적 PNG/JPEG를 읽기 전용으로 표시합니다. 텍스트 1 MiB, 이미지 원본 8 MiB, 이미지 축별 8,192픽셀, 총 1,600만 픽셀 및 RGBA 출력 64 MiB까지입니다. 큰 작업 허용으로 이 고유 상한을 늘릴 수 없습니다. 폴더, 링크, 다중 선택과 분할 입력은 미리보기를 지원하지 않습니다([PR125](https://github.com/Team-LJY/zipelo/pull/125)).
- **분할 7z:** 같은 폴더에 `.7z.001`부터 연속된 조각을 모아 첫 조각을 열면 목록과 해제를 지원합니다. 최대 999개이며 확정 가능한 누락은 정확한 파일명과 재시도 방법을 안내합니다. 목록 표시는 전체 파일 내용의 무결성 검증을 뜻하지 않습니다([PR126](https://github.com/Team-LJY/zipelo/pull/126)).
- **7z 만들기:** 만들기 화면에서 ZIP 또는 7z를 선택합니다. 7z는 LZMA2와 1 MiB 사전, non-solid 방식이며 한글 이름, 빈 파일과 폴더를 보존합니다. 암호가 필요하면 ZIP을 선택하세요([PR127](https://github.com/Team-LJY/zipelo/pull/127)).
- **손상 ZIP 복구:** 4 GiB 이하 단일 ZIP32의 비암호화 Store/Deflate 항목 중 검증 가능한 항목을 별도 비암호화 ZIP으로 저장합니다. 원본을 고치지 않으며 전체 복구, 부분 복구와 복구 불가를 구분합니다. 전체 목록을 알 수 없는 경우 경고를 유지하고, 일부 복구본 저장을 전체 성공으로 표시하지 않습니다([PR128](https://github.com/Team-LJY/zipelo/pull/128)).
- **TAR.BZ2와 TAR.XZ 풀기:** 기존 TAR, TAR.GZ와 함께 지원하며 파일 선택 필터와 저장 폴더 이름을 보완했습니다([PR119](https://github.com/Team-LJY/zipelo/pull/119)).

## 안전 동작과 설치 개선

- 같은 이름의 파일은 덮어쓰기, 건너뛰기와 이름 바꿔 저장을 선택하며 나머지 파일에도 같은 선택을 적용할 수 있습니다([PR114](https://github.com/Team-LJY/zipelo/pull/114)).
- 기본 작업 총량 16 GiB와 10,000개 항목을 넘으면 허용을 묻고 승인 후 최대 64 GiB와 200,000개까지 처리합니다. 압축률, 메타데이터, 진행 시간, 여유 공간, 경로 안전과 취소 제한은 계속 적용됩니다. 압축 TAR는 헤더와 패딩도 스트림 확장량으로 계산하므로 논리 파일 크기보다 먼저 상한에 도달할 수 있습니다([PR121](https://github.com/Team-LJY/zipelo/pull/121), [경계 검증 PR124](https://github.com/Team-LJY/zipelo/pull/124)).
- Windows는 기존 설치 위치에 업데이트하며 기본 앱 연결을 보존합니다. 제거할 때 다른 앱 선택을 안내하며 사용자의 선택을 강제로 바꾸지 않습니다. Ubuntu는 같은 사용자가 제거하고 기본 앱이 여전히 Zipelo이며 이전 앱이 유효한 경우 기록된 이전 앱으로 복원합니다([PR112](https://github.com/Team-LJY/zipelo/pull/112), [PR116](https://github.com/Team-LJY/zipelo/pull/116)).
- Ubuntu `.deb`의 X11 실행 의존성을 보완했고, 프로젝트 이동 후 긴 경로에서 시험 실행기가 멈추는 문제를 해결했습니다([PR122](https://github.com/Team-LJY/zipelo/pull/122), [PR118](https://github.com/Team-LJY/zipelo/pull/118)).

## 남은 한계

- RAR 압축과 해제는 제외합니다. 라이선스 걱정 없이 쓸 방법이 확인될 때만 다시 검토합니다.
- 암호화 7z 생성과 해제, solid 방식의 7z 생성, 분할 ZIP(`.zip.001`, `.z01` 계열), 분할 압축 만들기와 분할 입력 미리보기는 지원하지 않습니다. 지원하는 solid 7z의 기존 해제 범위와 solid 생성 미지원은 별개입니다.
- ZIP 복구는 4 GiB 초과, ZIP64 입력, 분할, SFX, 중앙 암호화와 미지원 압축 방식을 제외합니다. 암호화 항목의 내용이나 모든 손상의 복구를 보장하지 않습니다. 원본을 보관하고 복구본 내용을 확인하세요.
- 미리보기는 HTML/SVG/PDF, 애니메이션과 UTF-8 이외 인코딩을 지원하지 않습니다. JPEG는 8비트 baseline/progressive 범위이며 산술 부호화, lossless JPEG와 MPO는 제외합니다.
- AES 암호 ZIP의 Windows 탐색기 호환은 목표가 아닙니다. Zipelo나 7-Zip 등 지원 앱을 사용하세요. 암호를 잊으면 내용을 열 수 없습니다.
- 자원 제한은 모든 압축 폭탄 차단이나 프로세스 전체 메모리의 강제 격리를 보장하지 않습니다. 공간 검사는 예약이 아니며 실제 쓰기에서 실패할 수 있습니다. 실패 또는 취소 후 이미 게시된 결과나 정리에 실패한 임시 파일이 남을 수 있으므로 결과 안내를 확인하세요.
- 설치 파일은 서명되지 않았으며 서명 도입은 사용자 결정 대기입니다. 다른 Ubuntu 버전과 모든 Windows 환경의 호환을 검증한 것은 아닙니다. JAR 같은 앱과 문서용 컨테이너는 제품 범위에서 제외합니다.

## 검증 근거와 출시 전 남은 확인

다음은 각 PR 작성자와 리뷰어의 기록이며 이번 문서 변경에서 재실행한 결과가 아닙니다. 이전 커밋의 화면 검증을 최종 main에서 통과한 것으로 확대하지 않습니다.

- PR125 최종 JPEG 수정 기록: 전체 local 63단계, Rust 1,244개 및 미리보기 집중 23개 통과. Windows와 Wayland 화면 확인은 이전 커밋이며 최종 수정 뒤 재실행하지 않았습니다.
- PR126 최종 트리 기록: 전체 local 63단계와 Rust 1,297개 통과, 독립 도구 표본 및 원본/대상 변경 회귀 확인. Windows와 Wayland는 8ac2ccf 기준이며 이후 수정 뒤 재실행하지 않았습니다.
- PR127 최종 eec85f3 기록: 전체 local 63단계와 Rust 1,333개 통과. Windows와 Wayland 실제 생성/해제는 71aa755 기준이며 최종 수정 뒤 재실행하지 않았습니다. Windows 생성 중 취소 실기는 미수행입니다.
- PR128 최종 f44e860 기록: 전체 local 63단계와 Rust 1,366개 통과, 변형 201개의 기대 해시 및 원본 보존 확인. 최종 리뷰의 복구 Rust 시험 25개 통과. Windows와 Wayland GUI는 fec7fdd 기준이며 이후 수정 뒤 재실행하지 않았습니다.
- 출시 후보 main 3a77cfd의 Windows와 Ubuntu 26.04 Wayland/X11에서 네 새 기능, 잘못된 암호 재시도와 덮어 설치를 확인하는 작업은 bugfix 담당 진행 중입니다. OS 버전과 흐름별 결과가 확보되기 전에는 완료로 표시하지 않습니다.
- 해제, 7z 생성과 복구에서 디스크 부족, 동기화 실패와 정리 실패를 주입해 성공 오표시와 무관한 파일 삭제가 없는지 확인하는 backend 작업은 `fix/partial-output-cleanup`에서 진행 중입니다. 서명과 릴리스 준비에 대한 사용자 결정도 별도로 남아 있습니다.
